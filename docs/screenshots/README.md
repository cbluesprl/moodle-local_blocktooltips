# Screenshots

Place the screenshots referenced by the user guides and the Moodle.org plugin
page here. Capture them on a real site with **Edit mode on** and a user holding
`moodle/block:edit`.

Use these exact file names so the documentation links resolve:

| File | What to capture |
|------|-----------------|
| `01-settings.png` | The **top** of the plugin settings page (**Site administration → Plugins → Local plugins → Block tooltips**). Do **not** capture the whole page (one field per installed block is far too long). Show the heading + intro text and just 2–3 well-known blocks (e.g. HTML, Calendar, Activities) with a description filled in, cropped right below the third field. |
| `02-tooltip.png` | The **Add a block** popup with the info icon hovered, showing a tooltip. |
| `03-visibility.png` | A course in edit mode showing the eye icons on blocks (one visible 👁️ and one hidden 🚫 if possible). |

Recommended: PNG, cropped to the relevant area, width ~1000–1400 px.
For Moodle.org, also prepare at least one wider "hero" screenshot for the plugin
listing.
